Open 5250 ガイド

Open 5250 は、IBM i の上で動かす 5250 画面のサーバーです。パソコンにはブラウザーだけを用意し、管理画面からセッションを開始して 5250 画面をブラウザーのタブで開きます。RPG や CL からは ILE API (ライブラリー I5250) で操作できます。

1 配置と開始・終了

  • 配置先は /i5250 です。配置の手順は、配布物の README_ja.md を参照してください。
  • ILE API と CL コマンドは、配布物の保管ファイル I5250.SAVF からライブラリー I5250 に復元します (IBM i V7R4M0 以降。手順は Open 5250 マニュアル 2.2 節)。

管理画面の開始と終了 (管理者向け)

コマンド動き
I5250/STRI5250管理画面を開始します (バッチ・ジョブ I5250ADM、省略値はジョブ待ち行列 QSYS/QSYSNOMAX = サブシステム QSYSWRK)。RESTART(*YES) を指定すると、すべての 5250 セッションと管理画面を終了してから、管理画面だけを開始します。
I5250/ENDI5250すべての 5250 セッションと管理画面を終了します。OPTION(*CNTRLD) (省略値) はサインオン画面に戻るか切断されるまで DELAY の秒数 (省略値 *NOLIMIT = 無制限) だけ待ち、超えたら *IMMED と同じく SysReq → 90 でサインオフしてから切断します。値と省略値は ENDSBS と同じです。
  • 実行できるのは、ユーザー・クラスが *SECOFR のユーザーだけです。パラメーターの説明は F1 のヘルプにあります。
  • 5250 セッションの対話型ジョブは、管理画面とは別に QINTER で動きます。管理画面のジョブ I5250ADM だけを ENDJOB で止めても、5250 セッションは止まりません。
  • 経過は配置先の log/i5250cmd.log に記録されます。シェルからは start-admin.sh / stop-admin.sh でも開始・終了できます。

2 ブラウザーで使う

セッションの開始

方法操作
管理画面ブラウザーで http://<IBM i>:5250/ を開き、IBM i のユーザー ID とパスワードでログインします。
開始「新規セッションの開始」の見出しの横で「専用」(初期値) か「共用」を選び、「開始」を押します。クイック接続 (初期値) かプリセットかは、下のラジオボタンで選びます (コード・ページ・画面・プリセットを選び直すと、そのラジオボタンが選ばれます)。開始している間は、経過秒数を表示します (数秒かかります)。一覧の「開く」で、5250 画面をブラウザーの別のタブに表示します。
クイック接続プリセットを作らずに開始します。「ホスト・コード・ページ」と「画面」を選びます。ホスト・コード・ページの初期値は、IBM i の一次言語が日本語 (2962・2930) なら 5026 日本語カタカナ (IBM i Access Client Solutions の 930 に当たります)、それ以外なら 037 です。画面の初期値は 24x80 です。接続先は常にその IBM i の区画です。
プリセットで開始「プリセット」で接続構成を選びます (接続構成の「IBM i ホスト名またはIPアドレス」と「宛先ポート」で、この区画のほか別の IBM i にも接続できます)。プリセット一覧と AUTOTYP スクリプト一覧は畳んで表示しています。見出しを押すと開きます。
画面の開き方設定の窓 (「活動中のセッション」の見出しの右端の歯車) で、一覧の「開く」で 5250 画面を開く先を、「別のタブ」(初期値) か「別のウィンドウ」(アドレス欄やタブのない小さなウィンドウ) から選びます。選んだ値はそのブラウザーに保存されます。
リンクをコピー一覧の「開く」の横のコピーのアイコン (リンクをコピー) で、5250 画面のアドレスをクリップボードにコピーします。他の人に渡すと、その人のブラウザーで同じセッションを開けます (専用のセッションは、最初に開いた 1 つのタブだけが使えます)。

管理画面の右上の「ヘルプ」と、5250 画面のツールバーのヘルプ (丸で囲んだ i) で、このガイドを開きます。

ブラウザーでの操作

  • 5250 画面のアドレスは http://<IBM i>:<ポート>/ です。ポートは管理画面の一覧に表示されます。
  • タブやブラウザーを閉じても、セッションは終わりません (サインオンしたまま残ります)。一覧の「開く」でもう一度開くと、続きから操作できます。再読み込みしても同じです。
  • セッションを終えるときは、5250 画面でサインオフしてから、管理画面の一覧で「待ち」を選んで「切断」を押します。「待ち」はサインオン画面に戻るまで待ち、指定の秒数を超えたら「即時」に移ります。「即時」は SysReq → 90 でサインオフしてから切断します。サインオフが 15 秒以内に終わらないとき (保管・復元のような長い処理の途中など) は、そのまま接続を切ってセッションを終了します。このとき IBM i のジョブは、処理の区切りまで動き続けることがあります (IBM i Access Client Solutions で 5250 画面のウィンドウを閉じたときと同じです)。必要なら WRKACTJOB 等で確かめてください。
  • 5250 画面のツールバーの人のアイコンは、そのセッションが専用 (1 人) か共用 (2 人) かを表示します。押しても切り替わりません。共用か専用かは、セッションを開始するときに決まります。
  • IBM 5250 MCP にあるウィンドウモード切替とマイク (音声入力) のボタンは、Open 5250 では表示しません。
  • 表示設定 — ツールバーの切り替え (入力フィールド強調・桁区切り・シフト文字表示・点滅・十字線ルーラー・カーソル・ツールバー非表示・表示言語) は、使っているブラウザー (Cookie) に保存します。ポート番号に関わらず、同じブラウザーなら同じ設定で始まり、別のパソコンでは初期値です。フォントは、プリセットで開始したセッションならそのプリセットに保存します (クイック接続は毎回初期値)。
  • プリセットの保存先 — 1 プリセット 1 ファイルで、配置先の presets/<プリセット名>.i5250 (例 /i5250/presets/LOCAL.i5250) です。1 行に「キー=値」の形です。管理画面の「プリセット一覧」で作成・編集・削除できます。
  • 5250 画面そのものの操作 (キー・ツールバー・AUTOTYP 等) は、同梱の IBM 5250 MCP ユーザー・ガイド (IBM5250-MCP-User-Guide.pdf) を参照してください。IBM 5250 MCP と異なる動作・制約は Open 5250 マニュアル 4.7 節にまとめています。
  • 外字 (ユーザー定義文字) — IBM i は外字の値だけを送り、字形は送りません。管理画面の「設定」の窓 (歯車) の「IBM i 外字管理」で字形を取得すると、5250 画面の外字をその字形で描きます。
    • 「取得」を押すと、ユーザー ID とパスワードを聞く窓が開きます。この区画の FTP サーバーにつなぎ、CPYIGCTBL で QIGC3232 (32×32) と QIGC2424 (24×24) の利用者定義の外字を書き出して取得します (書き出し先は FTP のジョブの QTEMP で、IBM i にオブジェクトを残しません。パスワードは保存しません)。FTP サーバーが動いている必要があります (STRTCPSVR *FTP)。
    • 必要な権限: フォント表 (QIGC3232・QIGC2424) への *USE (IBM i セキュリティー「2 バイト文字セット・コマンド」)。*SECOFR クラスのユーザーで動作を確認しています。
    • 32×32 の字形を優先し、無い字は 24×24 で描きます。字形の無い外字 (未取得・未定義) は、点線の枠と斜線の字形で描きます。
    • 「表示」を押すと、別のタブに外字の一覧 (EBCDIC・PC (Shift-JIS)・Unicode のコードと、24×24・32×32 の字形) を表示します。
    • 外字を追加・変更したら、もう一度「取得」を押してください。コピーした外字は Unicode の私用領域の文字 (X'6941' = U+E000 から順) になります。
  • URL ホットスポット — 画面に表示された URL (http / https / www / mailto / ftp / file / gopher) には下線が付き、マウスのポインターが指の形になります。クリックすると新しいウィンドウで開きます (IBM i Access Client Solutions の既定「URL に下線を付ける」と同じです)。入力フィールドの中の URL は対象外です。
    • file:// の URL (例 FILE://GURI/IMG/658.JPG) は、ブラウザーが直接開けないため、Open 5250 がその IBM i の IFS からファイルを読んで返します。返すのは、そのセッションの今の画面に表示されている URL のファイルだけです。ファイルは、Open 5250 (管理画面のジョブ) を動かしているユーザーの権限で読みます (NetServer の共有の権限確認は通りません)。事前に該当のフォルダーを Explorer で開くなどして、利用者がアクセスできることを確認してください。
    • PC コマンド (STRPCCMD) — IBM i のプログラムが STRPCCMD でパソコンにファイルを開かせる命令 (START \\GURI\TMP\…\x.PDF のような START + 共有フォルダーのファイル・file://・http://) は、5250 画面のブラウザーの新しいウィンドウで開きます。PDF・テキスト・画像などブラウザーで表示できるものに限ります。ブラウザーが新しいウィンドウを止めたときは開きません。ブラウザーの設定で、このサイトのポップアップを許可してください。
      • IBM i 上でもパソコン上でも、コマンドは実行しません。Excel の起動のように、プログラムを動かすコマンドは使えません。
      • 開けるのは、そのセッションに IBM i が STRPCCMD で送った START ["題名"] [/オプション] 対象 の「対象」だけです。題名とオプションを除いた残り全部を 1 つの対象とみなし、先頭が http://・https://・www. なら URL、\\ホスト\・//ホスト/・file:// なら共有フォルダーのファイルとして扱います。それ以外は開きません (例と詳細は Open 5250 マニュアル 4.5.1 節)。ファイルの場所には下の「制約」が同じく当てはまります (NetServer の共有の定義にある共有名であること、その区画のファイルであること)。
      • テキストは UTF-8 として読めなければ Shift_JIS として表示します。
      • ファイル名に日本語 (DBCS) を含んでもかまいません。英小文字のファイル名が半角カタカナで渡る (5250 画面でも半角カタカナで見える) ときは、ツールバーの文字切替 (A / ｱ、Ctrl+F3) で英小文字に切り替えてから開いてください。PC コマンドの文字列は、そのときの文字切替に合わせて読みます。
    • 制約: file://ホスト/共有名/パス の共有名は、NetServer のファイル共有の定義 (QSYS2.SERVER_SHARE_INFO) で IFS のパスに直します (例: 共有 LMS が /tmp/PCDOC を指していれば、FILE://GURI/LMS/x.PPT は /tmp/PCDOC/x.PPT)。定義に無い共有名は開けません。また、ホスト名がその IBM i の区画 (システム名・ホスト名・IP アドレス) の場合だけで、他のサーバーのファイルは開けません (Open 5250 は CIFS のクライアントとして他のサーバーを読みません)。名前で一致しないホスト名は IBM i の名前の解決 (ホスト・テーブル・DNS) で IP アドレスに直し、この区画の IP アドレスなら開きます (名前の解決は時間がかかることがあるため、画面に file:// が出た時点で先に始め、結果を 10 分覚えます)。

複数のセッション

  • セッションは 1 件ごとに別のポート (5251 から順) を使い、IBM i では別の対話型ジョブとして動きます。別のプロセスのセッション同士は互いに影響しません (同じプロセスのセッションについては次の項目)。
  • 同時に動かせる数は、管理画面の「セッション数の上限」(既定 10 = ポート 5251〜5260) で決まります。
  • サーバー・プロセス (node) 1 つで受け持つセッションの数は、管理画面の「プロセスあたりのセッション数」(1 / 10 / 無制限、既定 10) で決まります。新しいセッションは、受け持つ数の最も少ないプロセスに入り、入れられるプロセスが無いときだけ新しいプロセスを起動します。プロセスを共用すると開始が速くメモリーも少なくて済みますが、そのプロセスが異常終了・強制終了すると、同じプロセスのセッションがすべて終わります。1 本のセッションの終了や IBM i との切断では、そのセッションだけが終わります。
  • 一覧の「装置名」は、IBM i がそのセッションに割り当てた表示装置 (例 QPADEV0003) です。対話型ジョブの名前にもなります。
  • 管理画面の「非活動タイムアウト」(5〜300 分、空欄 = なし) を設定すると、サインオンしているセッションで、その分数のあいだ IBM i とのやり取り (実行キー等の送信・画面の更新) が無ければ、「即時」と同じ手順で終了します。サインオン画面のままのセッションは対象外です。コマンドやプログラムの実行中 (キーボードがロックされている間。保管のように画面を出さずに長く動く処理も含みます) は非活動とみなさず、実行が終わって入力できるようになった時点から数え直します。時間が来たかどうかは 15 秒ごとに確かめるので、終了は指定の時間から最大 15 秒ほど遅れます。
    • 開いている 5250 画面には、まずサインオン画面が出て、すぐ (1〜2 秒後) に画面が空白になり、下の行に COMM659 (通信の切断) が出ます。セッションは終了しているので、その画面ではもう操作できません。続けて使うときは、管理画面で新しいセッションを開始してください。
    • 管理画面の一覧からは、5 秒ほどで消えます。
    • IBM i のシステム値 QINACTITV と同じ範囲の値ですが、処置は異なります。QINACTITV はジョブを終了 (QINACTMSGQ が *ENDJOB のとき) または切り離し (*DSCJOB のとき) します。Open 5250 はサインオフしてから接続を切り、セッションそのものを終了します。両方を設定したときは、先に時間が来た方が働きます。

共用と専用

モード動き
共用同じセッションを複数の人が同時に表示・操作するための特別な使い方です (通常の 5250 セッションは専用を使います)。同じセッションを複数のブラウザーやタブで開くと、全員が表示も入力もできます。一人の入力は、他の人の画面にも表示されます (表示までの遅れは、パソコンと IBM i の間の通信の往復時間に、サーバーが入力をまとめる 0.05 秒と、画面の処理の時間を足したものです。往復が約 0.025 秒の VPN 経由の接続で測った例では約 0.15 秒でした。回線の状況によって変わります。速く打つと、何文字かまとめて表示されます)。誰かが実行キーなどを押すと、全員の画面が次の画面に移ります。同じフィールドに同時に入力したときは、後から処理された人の値だけが残ります (2 人の文字が混ざることはありません)。
専用最初に 5250 画面を開いたタブだけが表示と入力をできます。他のタブ (同じブラウザーの別のタブ・同じパソコンの別のブラウザーのタブ・他のクライアント (別のパソコン) のブラウザーのタブ・「タブを複製」したタブのどれも。持ち主はブラウザーや人ではなくタブ単位です) で開くと、「このセッションは専用で、他の利用者が使用中です。」と表示し、そのタブを閉じます。使っているタブを閉じてから「専用の解放までの時間」(管理画面の設定、既定 5 分。0 = 約 5 秒) がたつと、他のタブで開けるようになります。使っているタブで再読み込みしても、そのタブが使い続けられます。使っているパソコンが落ちたり回線が切れたままになったりしたときは、応答が無くなってから 1 分の後に、さらに「専用の解放までの時間」を待ちます。
ご注意
  • 5250 画面のポートには認証がありません。ポート番号を知っている人は、共用のセッションを表示・操作できます。
  • 専用のセッションでも、サインオンしたままタブを閉じると、「専用の解放までの時間」(既定 5 分) の後に次に開いた人がそのサインオン済みの画面を使えるようになります。席を離れるときや使い終わったときは、サインオフしてください。
  • 専用で使っているタブが 1 分ほどサーバーに応答しないと (パソコンの停止・回線の切断、ブラウザーが裏のタブを眠らせたときなど)、そのタブは使用中でなくなり、他のタブで開けるようになります。そのタブに戻ったとき、他のタブが使っていなければ、そのまま使い続けられます。
  • 専用で他のタブを自動で閉じられるのは、管理画面の「開く」で開いたタブと、それを「タブを複製」したタブだけです。アドレス欄に URL を入れて開いたタブ (とその複製) などは、ブラウザーの制限で閉じられず、空白の画面のまま残ります (入力はできません)。手で閉じてください。
  • 管理画面から開始したセッションは、IBM i との接続が切れても自動では再接続しません。ホストが接続を閉じるとセッションを終了します。

3 RPG・CL から使う (ILE API)

CL プログラムからはコマンド (I5250xxx)、ILE RPG からはサービスプログラム I5250/I5250API の手続きで、5250 セッションを開始し、キーや文字を送り、画面を読み取れます。セッションはポート番号で指定します。

先に読んでください
  • 管理画面が動いている必要があります (セッションの開始・終了は管理画面が受けます)。受け付けるのは同じ区画 (127.0.0.1) からの要求だけで、認証はありません。
  • キーを送った直後の画面は、まだ前の画面のことがあります。次の画面を読むときは、キーを送る前の画面を取っておき、画面が変わるまで 1 秒おきに取り直します (下のサンプルの WAIT2)。「入力可」だけを条件にすると、前の画面を読んでしまいます。
  • サインオンの直後に「プログラム・メッセージの表示」などの画面が 1 枚はさまることがあります。カーソル位置が入力フィールドかを I5250FLD で確かめ、入力フィールドでなければ ENTER で進めます。
  • 行 (ROW) と桁 (COL) は 1 から数えます。0 は「現在のカーソル位置」です。データの位置 (属性バイトの次の桁) で指定します。
  • 文字はジョブの CCSID で受け渡します (変換は API が行います)。ジョブの CCSID が 65535 のときは既定の CCSID (DFTCCSID) を使います。
  • 同じセッションを複数のプログラムで使えますが、API に排他はありません。専用 (*DEDICATED) が断るのはブラウザーの他のタブだけで、API からの操作は断りません。同時に使い得るときは、呼ぶ側で順番を守ってください (例: 自分のライブラリーのデータ域を ALCOBJ で押さえてから使う)。
  • コマンド行から CALL ... PARM('...') で渡す文字のリテラルは、32 バイトまでしか確実に渡りません (IBM i の仕様)。長い値は CL プログラムの変数から渡します。

3.1 CL コマンド

失敗すると CPF9897 のエスケープ・メッセージを送ります (MONMSG MSGID(CPF9897) で受け、RCVMSG MSGTYPE(*EXCP) MSGDTA(&MSG) で理由を取り出します)。各パラメーターの説明は、プロンプト (F4) で F1 を押すとヘルプで確かめられます。

文法内容
I5250STR PRESET(プリセット名) MODE(*DEDICATED|*SHARED) PORT(&PORT)セッションを開始し、ポート番号を &PORT (*DEC 5 0) に返します。MODE の省略値は *DEDICATED (専用) です。CL プログラムの中でだけ使えます (値を返すため)。
I5250END PORT(n) OPTION(*CNTRLD|*IMMED) DELAY(*DFT|秒)セッションを終了します。*CNTRLD (省略値) はサインオン画面に戻るまで DELAY 秒 (0〜99999、*DFT = 管理画面の既定 300 秒) 待ち、戻らなければ SysReq → 90 でサインオフします。*IMMED はすぐに SysReq → 90 でサインオフします。サインオン画面ならどちらもすぐ終わります。
I5250KEY PORT(n) KEY(キー) ROW(行) COL(桁)キーを送ります。ROW・COL (省略値 0 = 現在の位置) を指定すると、カーソルをそこへ動かしてから送ります。キーの名前は下の表のとおりです。
I5250TXT PORT(n) TEXT(文字) ROW(行) COL(桁) KEY(ENTER|*NONE|キー)文字を入力してからキーを送ります (KEY の省略値は ENTER、*NONE なら入力だけ)。TEXT は 1024 バイトまでで、式が書けます。CL の変数をそのまま渡すと後ろの空白まで入力されるので、TEXT(%TRIMR(&USER)) のように書きます。
I5250PST PORT(n) TEXT(文字) ROW(行) COL(桁)指定位置を左上として、複数行を矩形に貼り付けます (改行 = X'25'、3000 バイトまで、キーは送りません)。TEXT には式が書けます。
I5250SCR PORT(n) SCREEN(&SCR) ROWS(&R) COLS(&C) CSRROW(&CR) CSRCOL(&CC) READY(&RDY)画面を取り出します。SCREEN (*CHAR 3564) は行を順につないだ文字で、n 行目は (n-1)*COLS+1 から COLS 桁です。ROWS・COLS・CSRROW・CSRCOL は *DEC 3 0、READY (*CHAR 1) は入力可なら '1' です。CL プログラムの中でだけ使えます。
I5250FLD PORT(n) ROW(行) COL(桁) LEN(桁数) TEXT(&T)指定位置の文字を取り出します (TEXT は *CHAR 3564)。LEN(0) (省略値) はその位置からフィールドの終わりまでで、入力フィールドでない位置なら CPF9897 になります。CL プログラムの中でだけ使えます。
I5250ATP PORT(n) SRCFILE(ライブラリー/ファイル) SRCMBR(メンバー)
または I5250ATP PORT(n) STMF('パス')		AUTOTYP スクリプトを、ソース・メンバー (SRCFILE の省略値 *LIBL/QAUTOTYP) かストリーム・ファイルから読んで実行します。読み込みのとき /tmp/I5250ATP-<ジョブ番号>.TXT に一時ファイルを作り、終わったら消します。

キーの名前 (KEY・Key に指定します。英大文字)

種類名前
実行キーENTER F1〜F24 PAGEUP PAGEDOWN (ROLLUP ROLLDN) HELP CLEAR PRINT PA1〜PA3 SYSRQ ATTN
カーソル移動TAB BTAB UP DOWN LEFT RIGHT HOME NEWLINE
編集RESET ERASE_EOF ERASE_INPUT FIELD_EXIT FIELD_EXIT_PLUS FIELD_EXIT_MINUS DEL INSERT DUP FIELD_MARK SPACE

3.2 RPG の手続き (サービスプログラム I5250/I5250API)

宣言は /COPY I5250/QRPGLESRC,I5250API_H、結合は H BNDDIR('I5250/I5250') で行います。戻り値はすべて戻りコード (10I 0、0 = 正常) で、0 以外のときは I5250_Error() で理由を取り出します。

手続き内容
I5250_Start(Preset : Mode : Port)セッションを開始します。Preset = プリセット名 (32A VARYING)、Mode = '*SHARED' / '*DEDICATED'、Port (10I 0) に開始したポートが返ります。
I5250_End(Port : Option : Delay)終了します。Option = '*CNTRLD' / '*IMMED'、Delay = 待ち時間 (秒、-1 = 管理画面の既定)。
I5250_SendKey(Port : Key : Row : Col)キーを送ります。Row・Col = 0 は現在の位置。
I5250_SendText(Port : Text : Row : Col : Key)文字 (32000A VARYING) を入力してからキーを送ります。Key = '*NONE' なら入力だけ。
I5250_PasteText(Port : Text : Row : Col)複数行を矩形に貼り付けます (改行 = X'25'、キーは送りません)。
I5250_GetScreen(Port : Screen : Rows : Cols : CsrRow : CsrCol : Ready)画面を取り出します。Screen は 3564A で、n 行目は (n-1)*Cols+1 から Cols 桁です。Ready = 1 なら入力可。
I5250_GetFieldText(Port : Row : Col : Length : Text)指定位置から Length 桁の文字を Text (3564A VARYING) に返します。Length = 0 はフィールドの終わりまで。
I5250_RunAutotyp(Port : Script)AUTOTYP スクリプトの本文 (65000A VARYING、改行 = X'25') を実行します。
I5250_RunAutotypStmf(Port : Path : Trim)ストリーム・ファイル (CCSID 1208) のスクリプトを実行します。Trim = '1' で行末の空白を落とします。
I5250_Error()直前の呼び出しのエラー・メッセージ (512A VARYING) を返します。

ソースは固定形式で書きます (H・D・P 仕様書は固定形式、演算は自由形式)。固定形式の D 仕様書では EXTPROC(*DCLCASE) は使えないため、宣言 (I5250API_H) では手続き名を EXTPROC('I5250_Start') のように文字で指定しています。

3.3 サンプル

次の 2 つのサンプルが、ライブラリー I5250 にプログラムとソース (QCLSRC・QRPGLESRC) で入っています。

プログラム内容
SMPSGN (ILE CL)コマンドを使い、サインオンして最初の画面を読み、SIGNOFF してセッションを終了します。CALL I5250/SMPSGN PARM('LOCAL' 'ユーザー' 'パスワード')
SMPSCR (ILE RPG)手続きを使い、セッションを開始して画面をジョブ・ログに書き出し、カーソル位置の入力フィールドの文字を取り出してから終了します。CALL I5250/SMPSCR PARM('LOCAL')

CL の例 (SMPSGN の要点。セッションを開始し、サインオン画面を待ってサインオンし、次の画面を読む)

             PGM        PARM(&PRESET &USER &PWD)
             DCL        VAR(&PRESET) TYPE(*CHAR) LEN(32)
             DCL        VAR(&USER) TYPE(*CHAR) LEN(10)
             DCL        VAR(&PWD) TYPE(*CHAR) LEN(32)
             DCL        VAR(&PORT) TYPE(*DEC) LEN(5 0) VALUE(0)
             DCL        VAR(&SCREEN) TYPE(*CHAR) LEN(3564)
             DCL        VAR(&BEFORE) TYPE(*CHAR) LEN(3564)
             DCL        VAR(&ROWS) TYPE(*DEC) LEN(3 0)
             DCL        VAR(&COLS) TYPE(*DEC) LEN(3 0)
             DCL        VAR(&CROW) TYPE(*DEC) LEN(3 0)
             DCL        VAR(&CCOL) TYPE(*DEC) LEN(3 0)
             DCL        VAR(&PROW) TYPE(*DEC) LEN(3 0)
             DCL        VAR(&READY) TYPE(*CHAR) LEN(1)
             DCL        VAR(&TRIES) TYPE(*INT) LEN(4)
             DCL        VAR(&LINE) TYPE(*CHAR) LEN(132)
             DCL        VAR(&MSG) TYPE(*CHAR) LEN(512)
             MONMSG     MSGID(CPF9897) EXEC(GOTO CMDLBL(ERROR))

/* セッションを開始 (ポートが &PORT に返る)       */
             I5250/I5250STR PRESET(&PRESET) MODE(*DEDICATED) +
                          PORT(&PORT)
/* サインオン画面が届くまで待つ (1 秒おき、最大 30 秒) */
             CHGVAR     VAR(&TRIES) VALUE(0)
WAIT1:       I5250/I5250SCR PORT(&PORT) SCREEN(&SCREEN) +
                          ROWS(&ROWS) COLS(&COLS) CSRROW(&CROW) +
                          CSRCOL(&CCOL) READY(&READY)
             IF         COND((&READY *NE '1' *OR +
                          &SCREEN *EQ ' ') *AND &TRIES *LT 30) +
                          THEN(DO)
             CHGVAR     VAR(&TRIES) VALUE(&TRIES + 1)
             DLYJOB     DLY(1)
             GOTO       CMDLBL(WAIT1)
             ENDDO
/* ユーザー (カーソル位置) とパスワード (1 行下) を入力し、 */
/* ENTER の直前の画面を &BEFORE に取っておいてから ENTER  */
             I5250/I5250TXT PORT(&PORT) TEXT(%TRIMR(&USER)) +
                          ROW(&CROW) COL(&CCOL) KEY(*NONE)
             CHGVAR     VAR(&PROW) VALUE(&CROW + 1)
             I5250/I5250TXT PORT(&PORT) TEXT(%TRIMR(&PWD)) +
                          ROW(&PROW) COL(&CCOL) KEY(*NONE)
             I5250/I5250SCR PORT(&PORT) SCREEN(&BEFORE) +
                          ROWS(&ROWS) COLS(&COLS) CSRROW(&CROW) +
                          CSRCOL(&CCOL) READY(&READY)
             I5250/I5250KEY PORT(&PORT) KEY(ENTER)
/* 画面が変わるまで待ち、1 行目をメッセージで出す   */
             CHGVAR     VAR(&TRIES) VALUE(0)
WAIT2:       I5250/I5250SCR PORT(&PORT) SCREEN(&SCREEN) +
                          ROWS(&ROWS) COLS(&COLS) CSRROW(&CROW) +
                          CSRCOL(&CCOL) READY(&READY)
             IF         COND((&READY *NE '1' *OR +
                          &SCREEN *EQ &BEFORE) *AND &TRIES *LT 30) +
                          THEN(DO)
             CHGVAR     VAR(&TRIES) VALUE(&TRIES + 1)
             DLYJOB     DLY(1)
             GOTO       CMDLBL(WAIT2)
             ENDDO
             CHGVAR     VAR(&LINE) VALUE(%SST(&SCREEN 1 &COLS))
             SNDPGMMSG  MSGID(CPF9897) MSGF(QCPFMSG) +
                          MSGDTA('1行目:' *CAT %TRIM(&LINE)) +
                          MSGTYPE(*INFO)
/* SIGNOFF を打ち、サインオン画面に戻るまで最大 30 秒待って終了 */
             I5250/I5250TXT PORT(&PORT) TEXT('SIGNOFF') KEY(ENTER)
             I5250/I5250END PORT(&PORT) OPTION(*CNTRLD) DELAY(30)
             RETURN

/* 失敗: 理由を受け取り、セッションを即時終了してから返す */
ERROR:       RCVMSG     MSGTYPE(*EXCP) MSGDTA(&MSG)
             IF         COND(&PORT *GT 0) THEN(DO)
             I5250/I5250END PORT(&PORT) OPTION(*IMMED) DELAY(0)
             MONMSG     MSGID(CPF0000)
             ENDDO
             SNDPGMMSG  MSGID(CPF9897) MSGF(QCPFMSG) MSGDTA(&MSG) +
                          MSGTYPE(*ESCAPE)
             ENDPGM

サインオン直後に「プログラム・メッセージの表示」などがはさまる場合の処理 (I5250FLD で入力フィールドかを確かめて ENTER で進める) は、SMPSGN のソースにあります。

RPG の例 (SMPSCR の要点。セッションを開始し、画面が届くまで待って、空白でない行をジョブ・ログに書く)

     HDFTACTGRP(*NO) ACTGRP(*NEW) BNDDIR('I5250/I5250')
     HCCSID(*CHAR:*JOBRUN)
      /COPY I5250/QRPGLESRC,I5250API_H
     DSMPSCR           PI
     D Preset                        32A
     DSleep            PR            10U 0 EXTPROC('sleep')
     D Seconds                       10U 0 VALUE
     DPort             S             10I 0 INZ(0)
     DScreen           S           3564A
     DRows             S             10I 0
     DCols             S             10I 0
     DCsrRow           S             10I 0
     DCsrCol           S             10I 0
     DReady            S             10I 0
     DTries            S             10I 0
     DIdx              S             10I 0
     DRowText          S            132A   VARYING
      * セッションを開始
       if I5250_Start(%trim(Preset) : '*DEDICATED' : Port) <> 0;
         Fail('開始できません: ' + I5250_Error());
       endif;
      * 入力可能になり画面が届くまで待つ (最大 30 秒)
       for Tries = 1 to 30;
         if I5250_GetScreen(Port : Screen : Rows : Cols
               : CsrRow : CsrCol : Ready) <> 0;
           Fail('画面を取り出せません: ' + I5250_Error());
         endif;
         if Ready = 1 and Screen <> *BLANKS;
           leave;
         endif;
         Sleep(1);
       endfor;
      * n 行目は Screen の (n-1)*Cols+1 から Cols 桁
       for Idx = 1 to Rows;
         RowText = %trimr(%subst(Screen : (Idx - 1) * Cols + 1
             : Cols));
         if RowText <> '';
           SendMsg(%char(Idx) + ': ' + RowText : '*INFO');
         endif;
       endfor;
      * 終了 (サインオン画面なら待たずに終わる)
       if I5250_End(Port : '*CNTRLD' : -1) <> 0;
         Fail('終了できません: ' + I5250_Error());
       endif;
       *INLR = *ON;
       return;

Fail (セッションを即時終了してからエスケープ・メッセージを送る) は SMPSCR のソースの終わりに、SendMsg は SMPSCR が取り込む I5250/QRPGLESRC,I5250MSG にあります。
